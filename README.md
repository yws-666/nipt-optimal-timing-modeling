# NIPT 最优检测时点选择与胎儿异常判定

> 2025 年全国大学生数学建模竞赛 C 题 · **广东赛区三等奖**
> 基于 1,082 条 NIPT（无创产前检测）临床数据，构建「影响分析 → 分组决策 → 异常判定」三段式建模方案

## 项目解决了什么

无创产前检测的准确性取决于胎儿 Y 染色体浓度是否达标（≥ 4%），而达标时间受孕妇 BMI、孕周等个体差异影响。本项目回答两个临床问题：

1. **不同体型的孕妇分别在第几周做检测最准？** —— 按 BMI 分组求解各组最佳检测时点
2. **如何自动判定胎儿染色体异常？** —— 机器学习分类模型 + 与传统 Z 值规则对比

## 核心结果

| 问题 | 方法 | 关键结果 |
|------|------|---------|
| 一：影响因素分析 | 数据清洗、皮尔逊相关、岭回归、混合效应模型 | 1,082 → 936 条有效数据；7 个显著指标；BMI 呈负向非线性影响 |
| 二：分组与时点决策 | 相邻互补分组算法、DBSCAN 去噪、风险损失函数、网格搜索、蒙特卡洛模拟 | 5 组 BMI 分组；最佳时点 10.9 → 13.4 周；高 BMI 组误差风险 +7.7% |
| 三：多因素与误差分析 | VIF 共线性诊断、PCA 降维、K-means 聚类 | 高 BMI 组达标时间显著延长（16.1 周 vs 13.1–13.5 周） |
| 四：异常判定模型 | GroupKFold 分组交叉验证、GridSearchCV、三模型对比 | GradientBoosting 准确率 84%、召回率 82.4%、F2 = 0.64，检出能力约为 Z 值规则 5 倍 |

## 运行方式

```bash
pip install -r requirements.txt
python 代码/1.1.py   # 依次运行 1.1 → 2.1 → 3.1 → 4.1
```

脚本基于自身位置自动定位数据与输出目录，四个脚本相互独立、可单独运行。
